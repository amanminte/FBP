1 Core Objectives & Quantitative Benchmarks

Track A: Pure Football Fundamentals (No Odds)

Uses strictly internal team ratings, goal expectancy, rolling momentum, and rest. Target: Push 1X2 Log Loss below 0.9900 and Accuracy into 51.5% – 54.5% on untouched 2024/25 fixtures.

Track B: Hybrid Market-Informed Engine

Synthesizes fundamentals with Pinnacle/Bet365 de-vigged implied probabilities and model-vs-market divergence. Target: Push Log Loss to challenge 0.9663 and Accuracy to 54.0% – 55.5%+.

Selective Confidence Filter ("Actionable Ticket Mode")

Human decision support does not place wagers on all 1,700 fixtures. The engine isolates the top-tier fixtures where calibrated probability ≥ τconf, ensemble disagreement is minimal, and expected value EV ≥ 3%. Tuned strictly on the 2023/24 validation split to deliver ≥ 55.0% to 62.0%+ verified hit rate on 2024/25 test matches.

2 Complete 7-Phase Execution Pipeline

Phase 1: Environment Setup & GPU Configuration Completed / Verified
  • Hardware Verification: Confirmed NVIDIA GeForce RTX 3050 GPU (6GB VRAM, CUDA 12.7 driver).
  • Dependency Stability: Resolved Windows Application Control policy by pinning official stable packages (NumPy 2.5, Pandas 2.2.3, Scikit-Learn, SciPy, Matplotlib, PyYAML).
  • Scaffolding: Structured modular directory hierarchy: config/, data/, src/, tests/, models/, reports/.
Phase 2: Historical Data Ingestion & Data Hygiene Code Built & Ready
  • Ingestion Scope: 6 complete seasons (19/20, 20/21, 21/22, 22/23, 23/24, 24/25) for Premier League, La Liga, Serie A, Bundesliga, and Ligue 1.
  • Network Resilience: load_data.py implements automated retry loops, exponential backoff, and local caching to effortlessly absorb 3-5 minute network drops.
  • Validation: validate_data.py handles date standardization, team canonicalization, score integrity, and proportional de-vigged market odds extraction.
Phase 3: Advanced Zero-Leakage Feature Engineering Code Built & Ready
  • Dynamic Elo Ratings: Home advantage adjusted (γ = 65), margin-of-victory scaled (ln(|ΔGoals| + 1)), promoted team prior (1,350), updating strictly post-match.
  • Pi-Ratings: Separate Home and Away team ratings tracking performance against expectation.
  • Dixon-Coles Bivariate Poisson: Exponential time-decayed attack/defense parameters, low-scoring correlation (ρ = -0.11), 8x8 scoreline matrix, Over/Under 2.5, and BTTS.
  • Shifted Multi-Horizon Form: Strictly shifted rolling windows (3, 5, 10, 20 matches) for PPG, SOT ratio, Corner ratio, 2nd-half momentum, rest differential, and schedule congestion.
  • Automated Leakage Unit Test: tests/test_no_leakage.py proves 100% bitwise feature invariance when future match results are corrupted.
Phase 4: Chronological Data Splits & Benchmark Suite Next Step
  • Warm-up Period: 2019/20 & 2020/21 (initializes multi-season Elo and 20-match rolling baselines).
  • Training Split: 2021/22 to Dec 31, 2023 (~4,500 matches).
  • Validation Split: Jan 1, 2024 to May 31, 2024 (~900 matches) for hyperparameter tuning & calibration.
  • Untouched Test Split: Full 2024/25 season (~1,728 matches).
  • Baselines: Majority Class, Competition Frequency, Pure Elo/Dixon-Coles, and Fair Market Odds.
Phase 5: Candidate Model Training, Ensembling & Calibration Upcoming
  • Algorithms: Regularized Multinomial Logistic Regression, Random Forest, HistGradientBoosting, LightGBM, and GPU-accelerated XGBoost / CatBoost.
  • Dual-Track Evaluation: Complete separate model suites for Track A (Pure Fundamentals) and Track B (Hybrid).
  • Probability Calibration: Isotonic & Sigmoid calibration fitted exclusively on the Validation split.
  • Convex Blending: Optuna-optimized ensemble weights minimizing multiclass Log Loss.
Phase 6: Comprehensive Evaluation & Decision-Support Simulator Upcoming
  • Metric Suite: Log Loss, Multiclass Brier Score, Expected Calibration Error (ECE), Accuracy, Macro-F1, Confusion Matrix, and League/Month breakdowns.
  • Ticket Simulation: Mode 1 (High-Confidence Straight Picks ≥ 55%), Mode 2 (Double-Chance Safety Filter), and Mode 3 (+EV 1-leg, 2-leg, 3-leg ticket bankroll backtesting).
  • Reporting: Saved figures (calibration curves, equity curves) and auto-generated reports/evaluation.md.
Phase 7: Transparent Prediction CLI & Streamlit Dashboard Upcoming
  • CLI Predictor: src/models/predict.py generates structured JSON/Markdown reports with 1X2 %, Over/Under %, Top 3 scorelines, Shannon Entropy uncertainty, and top contributing factors.
  • Streamlit Dashboard: Interactive web UI (streamlit run app.py) to filter test scoreboard, inspect tickets, and analyze any custom upcoming fixture.
